# PULSE 초동 개표방송

리센느 미니 4집 **PULSE**(2026.11.3 오후 6시 발매)의 한터차트 초동 판매량을 대한민국 선거 개표방송처럼 보여주는 팬 메이드 페이지예요.

## 화면 구성

- 개표 시작 카운트다운, 발매 후에는 초동 누적 득표(카운트업 애니메이션)
- 개표율: 초동 집계 기간(11.3 18:00 ~ 11.9 24:00)이 지난 비율
- 자체 최고 초동 맞대결: lip bomb 104,406장 vs PULSE
- 목표 선거구: 5만, 10만, 자체 최고, 15만, 20만, 30만을 넘으면 '당선' 도장
- 개표 추이 그래프, 일자별 득표, 시간 선거구(150시간) 지도, 역대 초동 순위, 하단 속보 자막
- 발매 전에도 `예시 화면 미리보기`로 개표 연출을 미리 볼 수 있어요 (예시 숫자는 저장되지 않아요)

## 숫자 넣는 법

### Claude 아티팩트 (기본)

1. 소유자 계정으로 페이지를 열면 오른쪽 아래에 **집계 입력** 버튼이 보여요.
2. 한터차트에 보이는 PULSE 초동 누적 판매량과 기준 시각을 넣고 **개표 반영**을 누르세요.
3. 페이지가 새 버전으로 저장되고, 보고 있는 모든 사람의 화면이 새 숫자로 갱신돼요.

잘못 넣은 집계는 같은 창의 목록에서 지울 수 있고, 비교 기록·목표 선거구·속보 자막·집계 기간은 설정에서 바꿀 수 있어요.

### GitHub Pages (선택)

1. 저장소 Settings → Pages에서 `main` 브랜치 루트로 배포해요.
2. `data.json`의 `snapshots`에 `{"t": "2026-11-03T19:00:00+09:00", "v": 52341, "m": "메모"}` 형식으로 한 줄씩 추가하고 커밋하면, 열려 있는 페이지가 1분마다 다시 읽어요 (GitHub Pages 캐시 때문에 최대 10분쯤 늦을 수 있어요).

## 파일

- `src/pulse.html`: 페이지 원본 (아티팩트에 올라가는 본문)
- `index.html`: `./build.sh`로 만든 단독 실행 버전
- `data.json`: GitHub Pages용 집계 데이터

## 출처와 면책

- 판매량은 한터차트 실시간 초동 수치를 운영자가 직접 옮겨 적은 값이에요. 한터차트 사이트를 자동으로 수집하지 않아요.
- lip bomb 초동 104,406장은 2025년 12월 3일 스포츠경향 보도 기준이에요.
- 한터차트, 소속사, 방송사와 관련 없는 비공식 팬 페이지예요.
